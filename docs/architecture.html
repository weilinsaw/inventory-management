Factory Inventory Management System

Architecture overview · Vue 3 + FastAPI demo application, in-memory mock data (no database)

Tech Stack

Frontend
  • Vue 3 (Composition API)
  • Vue Router
  • Vite (dev server / bundler)
  • Axios (HTTP client)
Runs on http://localhost:3000
Backend
  • Python + FastAPI
  • Pydantic (validation)
  • Uvicorn (ASGI server)
  • CORS middleware (allow all — demo only)
Runs on http://localhost:8001
Data
  • Static JSON files (server/data/*.json)
  • Loaded into memory at startup
  • No database — resets on restart
Loaded via mock_data.py

Request / Data Flow

1
Filter changed
FilterBar.vue updates useFilters.js composable state
2
View calls api.js
getCurrentFilters() builds query params
3
HTTP GET request
Axios calls FastAPI endpoint on :8001
4
In-memory filtering
apply_filters() / filter_by_month() in main.py
5
Pydantic validation
response_model shapes and validates the payload
6
Vue reactivity
Raw data stored in refs, derived via computed()
